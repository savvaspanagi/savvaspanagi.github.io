As power systems become increasingly complex, operator training requires simulation environments that can accurately reproduce system dynamics while meeting strict real-time constraints.

In this work, we evaluate the real-time performance of the open-source dynamic simulator Dynawo as the core engine of a modern operator-training platform. Using a large-scale model of the French transmission system and a range of realistic contingency scenarios, we investigate how network-model fidelity, topology representation, and solver settings affect computational performance.
