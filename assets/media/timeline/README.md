# Timeline photo archive

General collection of photos recovered from the old WordPress site / local backup.
Use these to assign `featured.jpg` (or `.jpeg` / `.png`) inside any `content/events/<slug>/` folder.

## Folders

- `from-photos-timeline/` — files from the local `Photos/Timeline` backup folder
- `from-wordpress-uploads/` — full-size images from WordPress `wp-content/uploads` (resized thumbnails excluded)

These files are for reference/selection. They are not automatically shown on the website unless copied into an event page bundle as `featured.*`.
